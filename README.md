# Adriana Garcés García

Mi sitio personal: <https://dgarcesg.github.io>

Está hecho con [Jekyll](https://jekyllrb.com/) y el tema [al-folio](https://github.com/alshedivat/al-folio), y se publica con GitHub Actions cada vez que se sube un cambio a `main`.

## Dónde se edita cada cosa

| Qué | Archivo |
| --- | --- |
| Bio y foto | `_pages/about.md`, `assets/img/prof_pic.jpg` |
| Publicaciones | `_bibliography/papers.bib` |
| Proyectos | `_projects/` |
| Repositorios | `_data/repositories.yml` |
| CV (pestaña) | `_data/cv.yml` |
| CV en PDF (sin dirección, teléfono ni correo) | `assets/pdf/CV_Adriana_Garces_Garcia.pdf` |
| Enlaces de contacto | `_data/socials.yml` |
| Color de resalte (guinda) | `$purple-color` en `assets/css/main.scss` |

## Privacidad

`CV/`, `ACADEMIC BACKGROUND/` y `PROFILE PHOTO/` están en `.gitignore` a propósito: traen datos personales y no deben subirse a este repositorio público.
